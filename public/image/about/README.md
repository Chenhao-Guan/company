# About Us 图片目录

## 用途

存放 About Us 页面的轮播图片

## 图片要求

- **文件名**:
  - about-1.jpg (或 .png, .webp)
  - about-2.jpg
  - about-3.jpg

- **尺寸**: 1600x1200 像素 (4:3 比例)
- **格式**: JPG, PNG, WebP
- **大小**: 每张图片建议 200KB - 500KB

## 图片内容建议

1. **about-1.jpg**: 公司仓库/办公环境
2. **about-2.jpg**: 质检车间/工作场景
3. **about-3.jpg**: 团队合影/办公文化

## 如何更新

将图片放到此目录后，代码会自动加载。如需修改文字说明，编辑 `components/about-section.tsx` 第 112-131 行。
